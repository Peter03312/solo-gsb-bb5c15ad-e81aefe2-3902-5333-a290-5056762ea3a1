记录每个事件的起始时间范围与持续分钟数。缺少时间范围的事件将作为“暂存”保存，暂不参与推算。 跨地区事故可在「时区」列填写 IANA 时区（如 Asia/Shanghai、America/New_York，留空表示不指定时区）； 指定时区后，最早/最晚开始须填写带 UTC 偏移的当地时间（如 2026-11-01T01:30-05:00）， 偏移须符合该时区当日夏令时规则，否则整次保存会被拒绝。带时区与未带时区的事件之间不能建立“先于”关系。

📎 事故现场证据：已保存的事件可上传文本（.txt/.log/.md/.csv/.json）、 PNG、JPEG 或 PDF（单文件不超过 20MB，扩展名须与内容一致）并填写说明；可查看文件名、大小、SHA-256 并下载原件。 附件跟随事件持续身份，改名和普通保存继续保留；移除附件只影响新版本，历史版本中的附件审阅者随时可回看下载。 新添加的事件请先“保存并重新推算”后再上传附件。

“先于”关系

A 先于 B：A 结束到 B 开始的间隔可设最短/最长等待（非负整数分钟，最长可空 = 不限）。 即 A 结束 + 最短等待 ≤ B 开始 ≤ A 结束 + 最长等待；不设置时按旧语义 A 开始 + A 持续 ≤ B 开始 推算。
